Modulo 2 de 4

Calculo de NC - paso a paso

La formula tiene un orden estricto: primero la diferencia sobre el neto, luego el IVA. Cambiar el orden infla el monto.
Ejemplo: precio cobrado $92/kWh vs correcto $82/kWh - consumo 310 kWh
Diferencia = $92 - $82 = $10/kWh
NC neta = $10 x 310 kWh = $3.100
NC total = $3.100 x 1,19 = $3.689
Error frecuente: calcular sobre el total con IVA → infla el monto. Siempre neto primero, luego x 1,19.

Modulo 3 de 4

Proceso de NC - pasos obligatorios

El proceso de NC tiene pasos obligatorios que protegen al cliente y al ejecutivo. Saltarse alguno genera responsabilidades.
1. Verificar el error en FPL9
Confirmar con datos objetivos antes de hacer nada. Sin esto la NC no tiene respaldo.
2. Calcular la NC correctamente
NC neta = diferencia neta. NC total = NC neta x 1,19. Verificar monto vs limite de autorizacion.
3. Obtener autorizacion si corresponde
Si el monto supera tu limite ($50.000): escalar al supervisor con el calculo completo.
4. Ingresar ticket el mismo dia
El ticket de NC se ingresa el mismo dia que se valida el error. Adjuntar el calculo y respaldo documental.
5. Informar al cliente
Confirmar numero de ticket, monto de la NC y cuando se vera el ajuste (proxima boleta o abono directo).
