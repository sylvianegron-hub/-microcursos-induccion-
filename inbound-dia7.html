Modulo 3 de 4

Manejo de expectativa de plazos

La clave del manejo de expectativa es ser honesto con el plazo real y ofrecer lo que SI se puede hacer.
Frases que generan problemas
En una hora le tenemos la luz / No depende de mi / Eso no es posible / Tiene que esperar nomas / Le prometo que hoy lo resolvemos
Frases que funcionan
El plazo es [X]. Voy a registrarlo como urgente. / Lo que si puedo hacer es [accion]. / Me comprometo a confirmarle cuando este listo. / Voy a escalar para acortar el tiempo.
